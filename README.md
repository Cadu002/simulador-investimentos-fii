# Simulador de Investimentos em Fundos Imobiliários

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio de Excel, com o objetivo de aplicar conhecimentos de cálculos financeiros e criação de ferramentas de simulação de investimentos.

A ferramenta permite realizar simulações relacionadas a investimentos em Fundos Imobiliários (FIIs), considerando informações como valor investido, período de investimento, rendimento e dividendos.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma planilha capaz de auxiliar na análise e simulação de investimentos em fundos imobiliários, permitindo visualizar a evolução do patrimônio e dos rendimentos ao longo do tempo.

## 🛠️ Tecnologias utilizadas

- Microsoft Excel
- Fórmulas e funções do Excel
- Cálculos financeiros
- GitHub

## 📊 Funcionalidades

A planilha permite:

- Simular investimentos em Fundos Imobiliários;
- Informar o valor investido;
- Analisar o período de investimento;
- Calcular rendimentos;
- Estimar dividendos mensais;
- Visualizar o patrimônio acumulado;
- Comparar a evolução dos investimentos ao longo dos anos.
